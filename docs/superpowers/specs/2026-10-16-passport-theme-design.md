# 지구 여권 디자인 (화면 새 단장) 설계

날짜: 2026-10-16 · 상태: 사용자 "진행해봐" (시안 1등 확인 후 진행)

## 1. 왜 하나

계획 2까지 마친 화면이 개발용 시제품처럼 보인다(사용자: "이거 디자인 너무한데").
- 흰 상자, 작은 회색 글씨, 납작한 남색 버튼
- 개발용 정보 카드("확대 단계 1.6")와 지도 프로그램 기본 버튼(+ − 나침반)
- 캐릭터는 나침반 이모지 하나

목표: 상업용 어린이 앱 수준의 완성도. 입체감, 눌리는 버튼, 종이 질감, 즐거운 디테일을 갖추되 깔끔하고 읽기 쉽게 만든다.

## 2. 정해진 것 (사용자 결정)

| 항목 | 결정 |
|---|---|
| 범위 | 화면 꾸밈 + 지도 색·글자 둘 다 |
| 분위기 | A. 종이 여권 스티커북 |
| 지구본 둘레 | 여권 표지 남색 하늘 + 작은 금색·크림색 별 |
| 캐릭터 | 동글이 (탐험 모자를 쓴 작은 지구), 표정 4가지 |
| 바꾸는 깊이 | 2. 겉모습 + 화면 배치 + 맞혔을 때 축하 동작 (소리·페이지 넘김은 안 함) |

고품질 시안 3개(진짜 여권 / 스티커북 / 그림책 여행일기)를 만들어 세 기준으로 심사했다.
- 심사 기준: 아이·부모 눈높이, 시각 완성도, 실사용·구현
- 결과: **'진짜 여권'이 2:1로 1등** (점수 합계: 여권 22.5, 스티커북 21.5, 그림책 21)

**기준 시안:**
- 시안 파일: [docs/design/2026-10-16-passport/mockup.html](../../design/2026-10-16-passport/mockup.html)
  - `?s=home|depart|mission|correct|wrong|stamp|chars`로 화면을 고른다.
  - `&n=3|4`는 보기 개수, `&t=초`는 움직임을 그 시점에서 멈춘다.
- 같은 폴더의 PNG: 390×844 휴대폰, 1024×768 태블릿 캡처.
- 색 값·질감·SVG(동글이, 장소 아이콘, 도구 아이콘, 문장)는 이 파일에서 그대로 옮겨 쓴다.

## 3. 디자인 바탕

### 색 (시안 `:root` 그대로)

| 이름 | 값 |
|---|---|
| 남색 | `--navy-900 #122039` · `800 #1A2C49` · `700 #23395B` · `600 #2D4870` · `500 #3A5A88` |
| 금색 | `--gold-200 #FBEBB8` … `500 #E9C46A` … `700 #A97E2E` · `--gold-ink #7A5B22` |
| 크림 | `--cream-50 #FFFDF7` · `100 #FCF7EA` · `200 #F6EEDC` · `300 #EADCBC` · `400 #D8C49A` |
| 글자 | `--ink #23395B` · `--ink-soft #4A5A75` · `--note #6B5A3E` |
| 빨강 | `--red #C23A2E` (도장에만 쓴다) |
| 초록 | `--green #2E9E5B` · `--green-ink #1E7543` · `--green-50 #EAF6EC` (정답) |
| 살구색 | 오답 카드 (시안 wrong 화면 값) |

### 질감

시안의 `--grain`, `--fiber`, `--guilloche`, `--linen`, `--leather`를 쓴다. 모두 작은 SVG 타일이나 CSS 그라데이션이다. 한 번 그려 반복하고, 움직이지 않는다.

### 글꼴

- 제목·버튼은 Jua, 글은 Gowun Dodum.
- `@fontsource/jua`, `@fontsource/gowun-dodum`으로 앱에 넣는다. 인터넷 없이도 보여야 하므로 외부 글꼴 주소를 쓰지 않는다.
- PWA 미리 저장 목록(`globPatterns`)에 `woff2`를 더한다.
- **지도 지명 글꼴은 지금처럼 기기 한글 글꼴을 그대로 쓴다.** 이유는 두 가지다.
  - 웹 글꼴은 글자 묶음별로 나눠 받는다. 그래서 지도 캔버스가 그릴 때 아직 안 받은 글자는 다른 글꼴로 섞여 그려진다.
  - 글꼴이 바뀌면 지명 수 기준(33 / 118 / 38 이상)이 흔들린다.

### 모양

- **카드:** '가죽 표지 + 크림 종이' 2겹이다. 남색 가죽 테두리에 금실 박음질(점선)을 두르고, 종이에 보안 무늬를 옅게 깐다.
- **큰 버튼:** 금박 그라데이션, 위쪽 또렷한 하이라이트 띠, 아래 입체 턱. 누르면 내려간다.
  - 시안에 있던 가운데 대각선 광택은 얼룩처럼 보인다는 지적이 있어 위쪽 띠로 바꾼다.
- **둥근 도구 버튼:** 테두리와 안쪽 면을 시안보다 밝게 해서 남색 하늘에 묻히지 않게 한다.
- **포커스 표시:** 금색 3px 테두리.

### 동글이 (`<Dongle mood size>`)

시안의 `dg-talk / dg-think / dg-happy / dg-comfort`를 옮긴다.

| 표정 | 몸짓 | 쓰는 때 |
|---|---|---|
| 기본 (talk) | 손 흔들기 | 이야기할 때 |
| 음… (think) | 턱 괴기 | 미션 중 |
| 신나요 (happy) | 만세 | 정답, 도장 |
| 토닥토닥 (comfort) | 하트 내밀기 | 오답 |

- 몸짓 체계는 그림책 시안에서 가져온다. 시안에는 '턱 괴기'가 없으니 더한다.
- 같은 SVG를 여러 번 그려도 그라데이션 id가 겹치지 않게 한다. 두 방법 중 하나를 쓴다.
  - 기호 모음(sprite)을 앱에 한 번만 둔다. 이때 `display:none`을 쓰면 Safari·Firefox에서 그라데이션이 사라지므로 0 크기로 숨긴다.
  - 컴포넌트에서 `useId`로 id를 고유하게 만든다.

### 아이콘

- 도구: 비행기, 닫기, 체크, 더하기, 빼기, 위성, 지구본, 북쪽, 책.
- 장소: 장소 id(pacific, asia, antarctica, seoul, dokdo, jeju, baekdu)별 그림이다.
  - 스티커북 시안처럼 하늘·바다 바탕이 있는 장면 그림으로, 표 위 칸을 꽉 채운다.
  - 그림이 없는 장소(계획 4에서 늘어날 곳)는 기본 지구 그림을 쓴다.
- 문장(지구·월계수·별)은 로고에 쓴다.

### 움직임

- CSS 키프레임만 쓰고, `transform`과 `opacity`만 움직인다. 필터 값은 움직이지 않는다.
- 움직임 줄이기를 켜면 다음과 같이 한다.
  - 전체 안전망: `*, *::before, *::after { animation: none !important; transition: none !important }`.
  - 각 장면은 멈춘 최종 모습으로 보인다. 도장은 자국만 보인다.

## 4. 화면별

### 첫 화면 (여행 전)

- **바탕:** 남색 하늘이다(리넨 결, 가죽 입자, 비네트, 별 몇 개, 화면 가장자리 금박 선). 지구본은 MapLibre 그대로이고, 지구본 밖이 투명해서 이 하늘이 보인다.
- **왼쪽 위:** 정보 카드(`InfoCard`)를 없앤다. 대신 가죽 알약 배지를 둔다(금박 문장 + '지구 여권' + 작은 'EARTH PASSPORT').
- **오른쪽 위:** MapLibre 기본 버튼(`NavigationControl`, `GlobeControl`)을 없애고 앱 버튼 `MapButtons`로 바꾼다.
  - 위성/그림 지도 바꾸기: 아이콘 아래에 작은 글자 '위성' 또는 '그림'.
  - 크게·작게: 한 줄 캡슐.
  - 지구본/평면 바꾸기.
  - 북쪽 위로: 지도가 돌아가거나 기울었을 때만 보인다.
  - 여행 중에는 지금처럼 숨긴다.
- **아래 시작 카드 (`TripLauncher`):**
  - 동글이(기본)와 말풍선 "어디로 떠나 볼까?"
  - 나이 탭: 유아 / 저학년 / 고학년. 움푹한 홈 안에서 고른 칸만 가죽으로 튀어나온다.
  - 단계 줄: "1단계 · 둥근 지구", "2단계 · 우리나라"
  - 장소 표: 절취선, 양옆 반원 홈, 위 칸 장면 그림. 표 크기를 맞추려고 4칸 격자로 놓는다(1단계 3장 + 빈 칸 장식).
- **가로 태블릿 (가로 ≥ 900px, 가로 방향):** 시작 카드가 여권 두 쪽 펼친 모양이 된다.
  - 왼쪽 쪽: 동글이 사진 칸, 말풍선, 나이 탭, 장식 MRZ 줄
  - 오른쪽 쪽: 표
- 새 버전 안내(`UpdateBanner`)와 위성 오류 안내(`SatelliteNotice`)도 크림 종이 카드로 바꾼다.

### 여행 카드 (`TripPanel`)

- **머리말 한 줄:** 비행기 배지, "제주도 여행 · 유아", ✕.
  - 그 아래에 보딩 패스처럼 절취선과 양옆 반원 홈을 둔다.
  - 미션 진행("미션 2 / 2" + 금화 점)은 절취선 아래 한 줄로 둔다. 390px 폭에서는 머리말 한 줄에 다 들어가지 않는다.
- 여행 중에는 왼쪽 위 로고를 숨긴다. 지도 위 목표를 가리지 않게 하려는 것이다.
- **카드 위치:** 휴대폰과 태블릿 모두 아래 가운데(최대 너비 약 560px). 지금의 카메라 여백 계산(`.bottom-stack` 높이 재기)을 그대로 쓰려는 것이다.
- **출발·둘러보기:** 동글이(기본)와 말풍선, 유아일 때 책 아이콘 + "부모님이 소리 내어 읽어 주세요.", 금색 큰 버튼 "출발!" / "미션 시작".
- **함께 이야기:** 크림 종이 카드에 "함께 이야기해요", 이야기 글, 부모님 메모 펼치기, 금색 "여행 마치기".

### 미션

- **진행 표시:** "미션 2 / 2"와 금화 점. 마지막 문제에서는 모든 점을 채우고, 지금 점에 테두리를 둘러 마지막임이 보이게 한다.
- **고르기:**
  - 동글이(음…, 56~64px), 질문 22px 이상.
  - 보기 카드: 점선 메달 안에 그림(이모지), 아래 입체 턱.
  - 보기 수별 배치: 2개는 2칸, 3개는 3칸, 4개는 2×2 가로형.
- **찾아 누르기·핀 꽂기·방향:** 지도를 많이 보여야 하므로 **압축 카드**를 쓴다. 390×844에서 카드는 화면의 30% 이하다. 방향 미션은 나침반 버튼 3×3이 들어가야 해서 40% 이하로 한다.
  - 들어가는 것: 머리말, 질문 한 줄, 안내 한 줄, 작은 동글이(40px).
  - 방향 미션의 방향 버튼은 나침반 모양으로 배치한다.
- **정답 뒤 (고르기):**
  - 결과가 나오면 보기 묶음은 숨기고, 정답은 결과 카드의 칩으로만 보여 준다(기준 시안 correct·wrong과 같음, 작업 9 결정 — 카드 높이 50% 안에 넣으려는 것).
  - 그 아래 초록 결과 카드: 동글이(신나요) 뒤 금빛 햇살, 색종이·반짝이(한 번만 터지고 멈춤), "잘했어요!", 칩 "🍊 귤 ✓", 설명 한 줄, 금색 "다음".
  - 동글이 깡충 뛰기는 2~3번만 한다.
- **오답 뒤:**
  - 살구색 카드에 동글이(토닥토닥), 제목 "괜찮아요, / 같이 알아봐요"(쉼표 뒤에서 줄바꿈), 정답을 알려 줄 때 칩 "정답: 🍊 귤".
  - 정답을 알려 주기 전 재시도 때는 고른 보기가 살구색으로 흐려진다. 유아 힌트 때는 정답 보기 둘레의 초록 빛이 깜빡인다. 결과가 나오면 보기 묶음은 숨는다.
  - 빨강은 쓰지 않는다.
- **찾아 누르기·핀 결과:** 압축 결과 카드(동글이 + 제목 + 한 줄 + 다음). 핀 별은 금색 별 3칸으로 보인다.
- 지금 쓰는 접근성 장치는 유지한다: `role="status"`, '다음' 버튼 설명 묶음(`aria-describedby`), 숨김 글자 "별 N개", 결과가 나오면 '다음'으로 초점 이동.

### 도장 (`StampCard`)

- **사증 쪽처럼 꾸민다:** 로제트 무늬, 장식 쪽 번호. 장식 글자는 `aria-hidden`.
- **빨간 잉크 도장:**
  - 이중 원 테두리, 둘레 글자(textPath), 장소 선 그림, 장소 이름, 날짜 띠.
  - 잉크가 덜 묻은 얼룩과 번진 가장자리는 SVG 필터로 만든다. 이 필터는 움직이지 않는다.
- **'쾅' 연출 (약 1.2~1.5초):** 나무 도장이 떨어짐 → 눌림 → 금색 '쾅!' 폭발과 퍼지는 잉크 고리 → 카드 살짝 흔들림 → 자국이 나타남 → 도장이 들려 사라짐.
  - 금색 '쾅!' 폭발과 잉크 고리는 스티커북 시안에서 가져온다.
- 동글이(신나요)와 말풍선 "다음엔 백두산에 가 볼까요?"를 둔다. 다음 장소가 없으면 말풍선을 빼고 "도장을 받았어요!"만 둔다.
- 옆에 '다음 도장 자리'를 둔다: 점선 원 안에 다음 장소 그림을 흐리게.
- "계속"은 처음부터 누를 수 있다.
- 고학년이 모은 별(★ N개)은 지금처럼 보인다.
- 도장을 저장하고 여권에 모으는 기능은 계획 3이다.

### 지도 색 (그림 지도만, 위성은 그대로)

- **땅:** 나라별 여러 색은 유지한다(이웃 나라를 구별하는 교육용). 다만 종이 시안과 어울리게 채도를 조금 낮춘 파스텔로 고친다.
- **바다:** 시안의 `#6BBDDE` 계열.
- **해안선:** 흰색 + 모래색 두 겹 선(스티커북 시안).
- **지명:** 남색 글자 + 크림색 테두리.
- 적도·날짜변경선 같은 선의 색은 새 바탕에서 잘 보이게 조정한다.

## 5. 지켜야 할 조건

- **지명 수:** 1280×800, 세 장면 ([127.5,36] z1.6, [127.8,36.3] z5.2, [127.6,36.6] z7.2)의 지명 수가 **33 / 118 / 38 이상**이어야 한다.
- **누르는 곳:** 48px 이상(유아 큰 버튼 56px 이상).
- **글자:** 본문 16px 이상, 질문 20~22px 이상, 대비 WCAG AA. 한국어는 `word-break: keep-all`.
- **카드 높이 (390×844):**
  - 시작 카드 ≤ 50%
  - 고르기 미션 ≤ 50%
  - 압축 카드 ≤ 30% (방향 미션 ≤ 40%)
  - 도장 ≤ 52%
- **작은 화면:**
  - 360×740, 375×667에서 넘침과 가로 스크롤이 없어야 한다.
  - 미션 카드는 화면의 55% 이하.
  - 넘칠 때는 카드 안에서 세로 스크롤한다.
- **태블릿:** 1024×768 가로에서 시안과 같은 느낌이어야 한다.
- **카메라:** 기존 여백 계산을 유지한다. 바뀐 카드 높이에서도 목표 지점과 정답 핀이 카드에 가려지지 않아야 한다.
- **기존 동작은 그대로:**
  - 7곳 × 3단계 = 21개 여행이 모두 끝까지 가야 한다.
  - 판정, 유아 잠금, 지구본 복원(`restore`)이 그대로 동작해야 한다. 지구본/평면 복원은 `MapButtons` 상태와도 맞아야 한다.
- 콘솔 오류 0.
- iPad Safari 대비: `mask`에는 `-webkit-mask`를 같이 쓴다. 가려지는 그림자는 부모의 `filter: drop-shadow`로 옮긴다.

## 6. 하지 않는 것

- 소리, 효과음, 배경음 (계획 4)
- 여권에 도장 모으기, 가족 프로필, 저장 (계획 3)
- 보기 이모지를 직접 그린 SVG로 바꾸기 (계획 4 콘텐츠 작업. 지금은 이모지 그대로)
- 지도 지명 글꼴 바꾸기 (3장의 '글꼴' 이유)
- 서울→목적지 하늘길 점선 (선택 사항이라 뺌)
