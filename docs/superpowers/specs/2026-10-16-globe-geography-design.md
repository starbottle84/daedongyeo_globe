# 지구본 지리 교육 콘텐츠 설계

- 작성일: 2026-10-16
- 상태: 사용자 검토 대기
- 저장소: `D:\결과물\대동여퀴즈_유아` (로컬 작업 → 깃허브 푸시)

## 1. 목적과 대상

유아부터 초등학생까지 **집에서 부모와 함께** 3D 지구본을 여행하며 지리를 익히는 교육용 웹앱.

- 대상: 유아(5~7세), 초등 저학년(1~3학년), 초등 고학년(4~6학년)
- 주 사용 장면: 태블릿·폰으로 집에서 부모가 옆에서 함께
- 핵심 차별점: **같은 지구본, 같은 장소를 나이에 따라 다른 놀이로** 경험한다. 형제가 한 기기에서 각자 수준으로 쓴다.

## 3. 전체 구조: 탐험 5단계 × 나이 3구간

나이 구간을 셋으로 나눈 이유: 유아는 글을 못 읽어 그림·소리로만 진행하고, 사회 교과는 3학년에 시작하며, 4~6학년에 지도 읽기·우리 국토·세계 여러 나라를 배운다.

| 탐험 단계 | 유아 · 그림과 소리 | 저학년 · 이름 익히기 | 고학년 · 위치와 원리 |
|---|---|---|---|
| 1. 둥근 지구 | 땅과 바다 구분, 큰 바다 찾아 누르기 | 대륙·대양 이름 고르기 | 대륙·대양 위치 정확히 찍기, 북극과 남극 차이 |
| 2. 우리나라 | 한반도 퍼즐, 서울·제주도 찾기 | 동해·서해·남해, 시·도 이름 | 시·도 위치, 독도, 산과 강 |
| 3. 이웃 나라 | 중국·일본·러시아·몽골 국기·동물 짝짓기 | 이웃 나라 이름·수도·국기 | 거리와 방향, 문화 비교 |
| 4. 세계 대륙 여행 | 랜드마크·동물 찾기 | 대륙별 대표 나라·국기 | 수도·인구·기후 |
| 5. 지구 탐험가 | 더운 곳과 추운 곳 | 큰 산맥·강·사막 이름 | 위도·경도, 적도와 회귀선, 시차 |

운영 규칙

- 모든 아이가 같은 단계를 쓰고, 프로필의 나이 구간에 따라 **할 일만 달라진다**.
- 단계는 1→5 순서로 열린다. 현재 단계 도장의 약 2/3를 모으면 다음 단계가 열린다 (예: 12곳 중 8곳).

## 4. 한 번의 여행 흐름

한 장소를 방문하는 5~10분짜리 묶음. 예시는 2단계 "독도".

| 순서 | 공통 | 유아 | 저학년 | 고학년 |
|---|---|---|---|---|
| 1. 출발 | 지구본이 목적지로 날아감 | 소리로만 안내 | 캐릭터 말 + 짧은 자막 | 날아가는 동안 위도·경도 숫자 표시 |
| 2. 둘러보기 | 그림 + 음성 30초 | 갈매기 소리, 섬 두 개 그림 | 동도·서도, 괭이갈매기 | 동도·서도와 89개 바위섬, 울릉도에서 약 87km |
| 3. 미션 3~5개 | 나이별 미션 유형 (6장) | 갈매기가 사는 섬 누르기 | 독도는 어느 바다? (동해/서해/남해) | 독도 위치 직접 찍기, 울릉도에서 본 방향 |
| 4. 도장 | 여권에 도장, 다음 목적지 예고 | 박수 소리 | 도장판 한 칸 채움 | 도장 + 정확도 별 1~3개 |
| 5. 함께 이야기 | 부모가 읽는 카드 1장 | 갈매기 소리 흉내 | 가 본 섬 같이 찾기 | 독도가 우리 땅인 이유 설명하기 |

원칙

- **유아는 실패가 없다.** 틀리면 정답이 반짝이는 힌트를 주고, 그래도 도장을 준다.
- **한 번에 5~10분.** 하루 여행 수는 부모 설정.
- **지구본 조작이 곧 놀이.** 유아 구간은 손으로 돌리다 길을 잃지 않도록 자동 이동하고, 확대 범위를 제한한다.
- 유아 구간은 모든 안내가 음성, 저학년은 음성 + 자막, 고학년은 자막 위주.

## 5. 부모와 함께하는 기능

1. **가족 프로필**: 아이별 이름·나이 구간·진행 상황. 형제 지원.
2. **어른 확인 잠금**: 설정·리포트 진입 전 확인 (숫자숲마을 `AdultGate` 패턴).
3. **함께 이야기해요 카드**: 여행 마지막 질문 카드.
4. **부모님 배경지식 카드**: 장소마다 한 줄 설명 + 정답 메모.
5. **가족 여행 핀**: 가족이 실제로 가 본 곳을 지구본에 표시.
6. **주간 리포트 · 하루 여행 수 설정**: 잘 아는 곳 / 헷갈린 곳, 여행 횟수.

## 6. 보상과 진행

- 장소 1곳 완료 = **도장 1개**. 단계 도장 2/3 → **다음 단계 열림**.
- 고학년: 정확도에 따라 **별 1~3개**, 별을 모으면 **숨은 장소**(예: 갈라파고스, 이스터섬) 열림.
- **다시 가 보기**: 미션에서 헷갈린 장소는 며칠 뒤 캐릭터가 다시 데려감 (실력 기반 복습을 진행 속에 숨김).
- 넣지 않는 것: 광고, 아이에게 보이는 결제 유도, 모르는 사람과의 순위 경쟁.

## 7. 미션 유형

콘텐츠는 아래 유형을 설정값으로 조합한다. 장소마다 새 코드를 짜지 않는다.

| 유형 | 내용 | 나이별 설정 |
|---|---|---|
| 찾아 누르기 | 지구본에서 장소·지역을 탭 | 정답 범위: 유아 넓게, 고학년 좁게 / 유아는 오답 시 정답 반짝임 |
| 고르기 | 2~4개 보기 중 선택 (글자 또는 그림) | 유아 2개(그림), 저학년 3개, 고학년 4개 |
| 위치 찍기 | 핀을 떨어뜨리고 정답과의 거리(km)로 채점 | 고학년 전용, 거리 → 별 1~3개 |
| 방향 고르기 | 기준 장소에서 본 방위 (동서남북, 8방위) | 저학년 4방위, 고학년 8방위 |
| 국기 짝짓기 (나중) | 나라와 국기 연결 | 3단계부터 |

## 8. 지도

### 8.1 보기 방식 (구현 완료)

- **그림 지도**: Natural Earth 나라 면을 파스텔 7색(MAPCOLOR7)으로 칠한 기본 보기.
- **위성 지도**: NASA Blue Marble 영상(NASA GIBS 타일, 확대 8단계까지) 위에 흰 글씨·검은 테두리 지명. 인터넷 연결 필요.
- 화면 왼쪽 위 카드의 버튼으로 전환하고, 마지막 선택을 브라우저에 기억한다.

### 8.2 데이터와 지명 표시

- 출처: Natural Earth (퍼블릭 도메인). `scripts/download-raw.mjs` → `data/raw` → `scripts/build-data.mjs` (`data/overrides.json` 보정 적용) → `public/data/*.geojson` (약 10MB).
- 지명은 한국어(`name_ko`), 없으면 영어. 확대할수록 대륙 → 나라 → 수도 → 바다·산맥 → 도시 → 시·도 → 산봉우리(높이) 순으로 늘어난다. Natural Earth 권장 확대 단계보다 1단계 일찍 보여준다.
- 강은 Natural Earth에 한국어 이름이 없어 주요 강 50여 개를 사전으로 붙였다.
- **지명 디테일 기준**: `D:\결과물\대동여퀴즈`에 띄운 지구본과 같은 수준을 유지한다. 앱으로 옮기거나 기능을 더해도 지명 층·표시 단계를 줄이지 않으며, 같은 위치·확대 단계에서 화면에 뜬 지명 수가 기준보다 적으면 안 된다.

### 8.3 보정 데이터 (첫 출시에 포함)

교육용으로 Natural Earth 그대로는 부족한 부분을 `data/overrides`(가칭) 보정 파일로 덧씌운다.

| 문제 | 보정 |
|---|---|
| 독도·울릉도 없음 | 장소 점 추가 (지명·좌표) |
| 어색한 번역 | "제주 아일랜드" → "제주도", "이즈-쇼토" → "이즈 제도" 등 수정표 |
| 교과서 표기와 다름 | "오스트레일리아 대륙" → "오세아니아" |
| 평양 중복 표시 | 같은 도시 일반 도시 점 제거 |
| 첫 화면에 "대한민국" 안 보임 | 한국·서울 표시 시작 단계를 앞당김 |
| 긴 공식 국명 | 북한·중국 짧은 이름 (반영 완료) |

## 9. 기술 구조

숫자숲마을(React 19 + Vite + TypeScript + zustand + vite-plugin-pwa + Capacitor)과 같은 구조로 만들고, `AdultGate`, `CharacterGuide`, `HintLayer` 같은 검증된 부품 패턴을 옮겨 쓴다 (의존성으로 공유하지 않고 복사).

| 단위 | 하는 일 | 의존 |
|---|---|---|
| 지구본 (`GlobeView`) | MapLibre 지구본 표시, 목적지로 날아가기, 탭 위치 전달, 보기 전환 | MapLibre, 지도 데이터 |
| 콘텐츠 (`content/`) | 장소·이야기·미션·카드·음성 경로를 JSON으로 보관하고 읽기 | 없음 |
| 여행 엔진 (`trip`) | 5단계 흐름 진행, 미션 순서 관리 | 콘텐츠, 미션 |
| 미션 (`missions`) | 유형별 화면과 정답 판정 (거리·범위·방위 계산) | 지구본 |
| 여권 (`passport`) | 도장·별·단계 열림 계산과 표시 | 저장 |
| 가족 (`family`) | 프로필, 어른 확인, 부모님 화면 | 저장 |
| 저장 (`storage`) | 기기 안에만 저장 (localStorage/IndexedDB) | 없음 |

장소 콘텐츠 예시 (형태 확인용):

```json
{
  "id": "dokdo",
  "stage": 2,
  "name": "독도",
  "center": [131.866, 37.241],
  "story": { "preschool": "...", "lower": "...", "upper": "..." },
  "missions": {
    "preschool": [{ "type": "tap", "target": "dokdo", "radiusKm": 80 }],
    "lower": [{ "type": "choice", "question": "독도는 어느 바다에 있을까?", "options": ["동해", "서해", "남해"], "answer": 0 }],
    "upper": [{ "type": "pin", "target": [131.866, 37.241] }, { "type": "direction", "from": "ulleungdo", "answer": "동남" }]
  },
  "familyTalk": { "preschool": "...", "lower": "...", "upper": "..." },
  "parentNote": "...",
  "audio": { "preschool": "audio/dokdo-preschool.mp3" }
}
```

- 저장: **로그인 없이 기기 안에만** 저장. 만 14세 미만 개인정보 수집 시 필요한 보호자 동의 절차를 첫 출시에서 피한다.
- 배포: 깃허브 저장소 → GitHub Pages. 태블릿에서 열고 홈 화면에 추가하면 앱처럼 쓴다.
- 음성: 유아 구간용 음성은 미리 만든 음성 파일로 넣는다 (기기마다 품질이 다른 브라우저 음성 대신).
- 국기(3단계부터): 무료 공개 라이선스 국기 SVG를 쓴다.

## 12. 확인 방법

사용자 규칙에 따라 새 기능에는 테스트를 따로 만들지 않고, 버그를 고칠 때만 재현 테스트를 쓴다. 대신 단계마다 아래로 확인한다.

- 콘텐츠 검사 스크립트: 24곳 모두 나이 3구간의 이야기·미션·카드가 빠짐없이 있는지, 좌표가 올바른지 확인.
- 브라우저 직접 확인: 나이 구간별로 여행 1번을 끝까지 진행 → 도장이 여권에 남는지, 새로고침 후에도 유지되는지.
- 태블릿 크기 화면에서 지구본 조작, 글자 크기, 버튼 누르기 편한지 확인.
