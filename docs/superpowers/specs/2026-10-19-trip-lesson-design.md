# 여행 수업: 저학년·고학년이 문제 전에 내용을 훑는 단계

**날짜:** 2026-10-19
**사용자 말:** "저학년 고학년은 스토리텔링 형식이나 수업 형식으로 한번 싹 훑은 다음에 답을 맞추게 해야하지 않을까 싶네"

## 문제

저학년·고학년 여행은 출발 → 둘러보기(이야기 한 문단) → 미션 4·5개 → 도장 순서다.
둘러보기 이야기에는 문제에 나오는 내용이 거의 없다. 예: 사하라 사막 저학년 문제에는 사헬·대상·나미브 사막·아틀라스산맥이 나오는데 이야기에는 없다.
그래서 아이는 배운 적 없는 것을 바로 맞혀야 한다.

## 결정 (사용자 확인 2026-10-19)

| # | 항목 | 결정 |
|---|---|---|
| L1 | 형식 | **수업형.** 이번 여행에 고른 문제의 해설(`explain`)로 수업 장면을 자동으로 만든다. 새 글을 쓰지 않고, 배운 것과 문제가 늘 맞는다 |
| L2 | 장면 수 | 맨 앞에 지금의 둘러보기 이야기(`story`) 1장, 그다음 고른 문제 하나에 1장. 저학년 1+4장, 고학년 1+5장 |
| L3 | 지구본 | 장면마다 움직인다. 찾아 누르기·핀 꽂기 → 찾을 곳으로 날아가 초록 핀 + 이름표. 방향 → 답한 뒤 화면처럼 방위표 정답 칸 + 도착 핀. 고르기·이야기 → 장소 화면 |
| L4 | 건너뛰기 | 늘 넣는다. 마지막 장이 아닐 때 버튼 아래 작은 글자 버튼 "건너뛰고 문제 풀기" |
| L5 | 유아 | 넣지 않는다. 유아 여행은 지금과 똑같다 |
| L6 | 음성 | 저학년·고학년은 지금도 성우 음성이 없으므로 글만 |
| L7 | 문제 더 풀기 | 새로 고른 문제로 수업을 한 번 더 한다(이야기 장 없이 4·5장) → 미션 |
| L8 | 답 미리 보이기 | 수업이 답을 알려 주는 셈이지만 "배운 다음 맞히기"가 목적이라 그대로 둔다. 답한 뒤 해설이 한 번 더 나와 복습이 된다 |
| L9 | 해설 필수 | 저학년·고학년 문제는 모두 해설이 있어야 한다(`check:content` 오류). 지금 빠진 6개(아시아·남극·오세아니아·남아메리카·태평양·대서양 저학년 '그곳 찾기')에 한 줄씩 넣는다 |

## 화면

카드는 지금 여행 카드(보딩 패스) 그대로, 둘러보기 단계 본문만 바뀐다.

```
여행 수업 2 / 5   ● ● ○ ○ ○      ← 미션 진행 줄과 같은 모양
● 아틀라스산맥                    ← 지도 장면만. 초록 점 = 지도 위 초록 핀
(동글이) 해설 말풍선
[ 이전 ]      [ 다음 ]            ← 첫 장은 [다음]만, 마지막 장은 [미션 시작]
      건너뛰고 문제 풀기          ← 마지막 장에서는 뺀다
```

- 방향 장면의 이름 줄: `기준 → 목표` (예: 카이로 → 은자메나)
- 국기 고르기 장면: 이름 줄 대신 국기 그림 (질문 국기 `flag` 또는 정답 보기 국기)
- 고학년 핀 꽂기는 수업 때 지명이 보이고, 미션에서만 사라진다

## 구조

- `src/trip/lesson.ts` — `lessonScenes(place, tier, picked, withStory)`: 장면 목록 (순수 함수). 유아는 이야기 1장만(또는 0장)
- `src/trip/LessonView.tsx` — 장면 한 장: 진행 줄·이름 줄/국기·말풍선·버튼, 지구본 움직이기
- `src/trip/tripReducer.ts` — `sceneIndex`·`sceneCount`, 동작 `prev`·`skip`, `next`가 장을 넘기고 마지막 장에서 미션으로. `more`가 수업부터
- `src/trip/TripPanel.tsx` — 저학년·고학년 둘러보기 자리에 `LessonView`
- `src/dev/shotParams.ts` — `?shot=sahara:lower:explore3` = 여행 수업 3번째 장
- `scripts/check-content.ts` — 저학년·고학년 해설 필수

## 남는 것 (따로 할 일)

해설 몇 개는 질문 없이 읽으면 뜻이 덜 통한다(예: "낮 12시에서 8시간을 거꾸로 세면 오전 4시예요" — 어느 나라 이야기인지 없다). 이번에는 그대로 두고, 따로 골라 고친다.
