# 계획 6: 3~5단계 장소 36곳

**Goal:** 설계(2026-10-16-globe-geography-design.md 3장 표)의 3~5단계를 만든다. 단계마다 12곳, 장소마다 1·2단계와 같은 묶음(유아 8·저학년 12·고학년 12)이다. 유아 음성 녹음은 빼고, 녹음 대본은 빌드가 자동으로 늘린다.

**사용자 결정 (2026-10-19):** "목소리 빼고 나머지 다 해봐" → 아래 장소 목록과 새 기능 두 가지로 시작하기로 확인.

| # | 항목 | 결정 |
|---|---|---|
| D1 | 장소 36곳 (이 순서가 시작 카드 순서) | 아래 표 |
| D2 | 묶음·종류 | 1·2단계와 같다 (계획 5 D1·D5). check:content가 막는다 |
| D3 | 단계 열림 | 규칙 그대로(앞 단계 12곳 중 8곳) |

| D5 | 국기 문제 | 고르기에 두 가지: ① 질문 국기 `"flag": "jp"` + 글자 보기("이 국기는 어느 나라?") ② 국기 보기 `options[].flag` — 보기는 국기 그림만 보이고 글자는 화면 읽기·결과 칩에만 쓴다("일본 국기를 골라 봐"). 유아는 국기 보기가 그림(icon) 대신이 된다 |
| D6 | 나라 누르기 | 찾아 누르기에 `"country": "중국"`(countries.geojson의 ko 이름). 그 나라 땅 어디를 눌러도 정답. `area`·`country`·`radiusKm` 중 꼭 하나만 쓴다 |
| D7 | 예민한 주제 | 대만·티베트·영토 분쟁·전쟁·정치 체제는 넣지 않는다. 일본 쪽 바다는 지도대로 '동해', 독도는 우리 땅 그대로 둔다(문제로 다투지 않는다). 나라를 깎아내리는 비교를 하지 않는다 |
| D8 | 장면 그림 | 36곳 모두 1·2단계와 같은 화풍의 64×50 장면(`pl-<id>`). 국기·상표는 넣지 않는다 |
| D9 | 사실 확인 | 쓰는 에이전트와 확인하는 에이전트를 나눈다(계획 4 D10) |

## 쓰는 기준

- 계획 4 '콘텐츠 작성 기준'(2026-10-17-plan4-content-voice.md 37~60줄)을 그대로 지킨다: 나이 눈높이, 정답 위치 골고루, 지도에 보이는 답 피하기, 방향 문제, 찾아 누르기, 위치 찍기, 사실(숫자는 교과서·공공기관 값에 '약'), 부모님 메모, 함께 이야기.
- 형식은 지금 장소 파일과 같다(예: `src/content/places/seoul.json`, `europe.json`). 미션 한 줄에 하나.
- 방향 문제: 대권·평면 지도 방위 모두 칸 경계에서 10° 넘게(검사가 막는다). 고학년 8방위, 저학년 4방위.
- 국기 질문은 장소마다 문구를 다르게 쓴다(같은 질문이 여러 장소에 나오면 검사가 알린다).
- 확인: `npm run check:content -- --only <id들>` 오류 0·알림 0. 앱에 등록한 뒤 `node scripts/measure-directions.mjs <w> <h> <id들>`(6개 화면 크기) 걸린 것 0.
