# 계획 8: 나라 수도 퀴즈 (+ 유아 국기 퀴즈)

**사용자 결정 (2026-10-23):** "모든 국가별 수도 맞추는 게임도 하나 만들어봐" → 제안대로, 유아도 포함(국기 그림 놀이), 시안 없이 바로 만들기.

## 결정 사항

| # | 항목 | 결정 |
|---|---|---|
| D1 | 들어가는 곳 | 시작 화면(여권 펼친 면) 오른쪽 맨 위의 '퀴즈' 카드. 여행과 따로 노는 놀이다. 여행처럼 아래 카드 자리에 퀴즈 카드가 뜬다 |
| D2 | 나라 범위 | UN 회원국 193개에서 이스라엘(수도 분쟁)과 나우루(공식 수도 없음)를 뺀 191개. 대만·코소보·팔레스타인 등 인정이 갈리는 곳은 넣지 않는다(계획 6 D7과 같은 원칙) |
| D3 | 수도가 여럿인 나라 | 외교부·교과서가 수도로 적는 하나를 정답으로 한다(예: 볼리비아 수크레, 남아프리카 공화국 프리토리아, 네덜란드 암스테르담). 다른 수도는 보기에 넣지 않는다 |
| D4 | 표기 | 나라 이름은 외교부 국가 표기, 수도 이름은 국립국어원 외래어 표기(용례)를 따른다. 지도 지명과 다르면 아이에게 익숙한 짧은 이름(예: 서울특별시 → 서울) |
| D5 | 대륙 | 아시아·유럽·아프리카·북아메리카(중앙아메리카·카리브 포함)·남아메리카·오세아니아. 지도 데이터(countries.geojson continent)를 따르고, 대양의 섬나라는 가까운 대륙에 넣는다 |
| D6 | 쉬움 단계 | level 1(누구나 아는 큰 나라·이웃 나라, 약 40개) · 2(교과서에 자주 나오는 나라) · 3(나머지). 저학년은 1·2부터, 고학년은 전부 |
| D7 | 한 판 | 대륙 하나(또는 전체 섞기)를 골라 저학년·고학년 10문제, 유아 5문제 |
| D8 | 문제 | 저학년: "○○의 수도는?" 국기 + 보기 3개(같은 대륙 수도). 고학년: 보기 4개 + 가끔 거꾸로("수도 ○○는 어느 나라?" — 지명을 숨기고 수도 자리만 보여 줌) + 수도 자리 찍기(별). 유아: 지구본에서 반짝 칠한 나라의 국기를 그림 2개 중에서 고르기 |
| D9 | 지구본 | 문제마다 그 나라로 날아가 땅을 칠한다. 문제를 푸는 동안 지도에서 수도 이름표를 숨기고, 답한 뒤 수도 자리에 표시를 보여 준다. 아주 작은 나라는 반짝이 원으로 자리를 알려 준다 |
| D10 | 도감 | 나라마다 두 번 맞히면 국기 스티커가 붙는다(유아는 국기 도감, 저·고학년은 수도 도감). 틀린 나라는 다음 판에 먼저 나온다 |
| D11 | 국기 | flag-icons(MIT)에서 191개국 국기를 src/assets/flags에. 국기는 JS에 넣지 않고 파일로 내보내 오프라인 저장(PWA)에 들어가게 한다 |

## 데이터: src/content/capitals.json

```json
{ "countries": [
  { "code": "kr", "iso3": "KOR", "country": "대한민국", "capital": "서울", "capitalAt": [126.978, 37.566],
    "region": "asia", "level": 1, "focus": [[124.6, 33.1], [131.9, 38.6]] }
] }
```

- `code`: ISO 3166-1 두 글자 소문자 (국기 파일 이름 `src/assets/flags/<code>.svg`)
- `iso3`: `public/data/countries.geojson`의 `id`와 같은 세 글자 (지구본에서 땅 칠하기). 지도에 그 나라 면이 없으면 빼지 말고 그대로 두되 `focus`로 자리만 알린다
- `country`·`capital`: D4 표기
- `capitalAt`: 수도 도심 [경도, 위도]
- `region`: `asia` · `europe` · `africa` · `north-america` · `south-america` · `oceania`
- `level`: 1 · 2 · 3 (D6)
- `focus`: 카메라를 맞출 [남서, 북동] 두 점 — 그 나라 본토(가장 큰 땅)와 수도를 감싼다. 날짜변경선을 넘는 나라(러시아·피지·뉴질랜드 등)는 경도를 180 넘게 써서 이어지게 한다
- 만드는 스크립트: `scripts/build-capitals.mjs` (data/raw 의 Natural Earth + public/data + 손으로 정한 표기 표). 검사: `npm run check:content`가 capitals.json도 본다
