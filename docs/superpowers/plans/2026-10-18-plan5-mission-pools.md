# 계획 5: 장소별 문제 묶음과 무작위 출제 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 장소·나이 구간마다 문제 묶음을 두고, 여행 한 번에 그중 몇 개를 골라 낸다. 같은 장소를 다시 가도 새 문제가 나온다. 설계의 '여행 한 번에 미션 3~5개'를 맞춘다.

**Architecture:**
- 콘텐츠 형식은 그대로다. `missions[tier]` 배열이 곧 '문제 묶음'이다.
- 여행을 시작할 때 `pickMissions()`(순수 함수)가 묶음에서 이번 여행 문제를 고른다. 고르는 기준은 세 가지다: 아이가 안 푼 문제 먼저, 문제 종류 섞기, 정해진 순서.
- 푼 문제 기록은 프로필 진행에 더한다(장소별 문제 id 목록).
- 문제 id는 문장 해시로 만든다. 콘텐츠에 칸을 더하지 않으려는 것이다(음성 id와 같은 방식).

**Tech Stack:** React 19, Vite 6, TypeScript 5.7, MapLibre 6.14

| D2 | 여행 한 번 문제 수 | 유아 **3**, 저학년 **4**, 고학년 **5** |
| D3 | 고르는 규칙 | 안 푼 문제를 먼저 고른다. 묶음을 다 풀었으면 오래전에 푼 것부터 다시 돈다. 종류별로 꼭 하나씩 넣는다: 유아는 누르기 1·고르기 1, 저학년은 누르기 1·방향 1·고르기 1, 고학년은 핀 1·방향 1·고르기 1. 남은 칸은 종류를 가리지 않고 안 푼 것부터 채운다(작업 2에서 정함 — 묶음 전체가 고르게 돌게). 같은 순위끼리는 무작위다 |
| D4 | 문제 순서 | 지도 미션(누르기·핀)을 먼저, 고르기를 가운데, 방향을 끝에 둔다. 카메라 이동이 덜 어지럽고 지금 흐름과 비슷하다 |
| D5 | 묶음 안 종류 최소 | 유아: 누르기 ≥2, 고르기 ≥4. 저학년: 누르기 ≥3, 방향 ≥3, 고르기 ≥4. 고학년: 핀 ≥3, 방향 ≥3, 고르기 ≥4 |
| D6 | 도장·별 | 고른 문제를 다 마치면 도장이다(지금과 같음). 고학년 별은 이번 여행의 핀 별 합이고, 장소 최고 기록을 남긴다 |
| D7 | 부모님 공간 | 정답 목록은 묶음 전체를 보인다. 구간별로 접고, 이미 푼 문제에는 표시를 붙인다 |
| D8 | 음성 | 유아 묶음 문제 전부(질문·설명)를 녹음 대본에 넣는다(약 500문장). 녹음은 계속 '나중에'다 |
| D9 | 콘텐츠 품질 | 지금과 같은 '콘텐츠 작성 기준'을 따른다(계획 4 문서). 쓰는 에이전트와 확인하는 에이전트를 나눈다. 이번에 기존 문제도 함께 다시 보며 '어른도 헷갈릴 수 있는 보기'를 고친다. 예: 아시아 캥거루 보기 — 호주가 아시아축구연맹에 속해 헷갈릴 수 있었음 |
| D10 | 개발용 주소 | `?shot=장소:구간:missionN`은 고정 시드로 고른 문제 중 N번째를 연다. `?pool=all`을 붙이면 묶음 전체를 차례로 연다(화면 확인용) |
